Guía 7 · Resumen de la parte técnica

Codificar los módulos del software

En esta guía se pasa del diseño a la codificación. Se usa Git para versionar el código, Java (JDBC, Servlets, JSP y frameworks) para el back-end, React para el front-end y servicios web (API) que se prueban con Postman.

Requisitos que se repiten

  • El proyecto debe estar en un repositorio Git, y el ZIP lleva un archivo con su enlace.
  • El código lleva comentarios y cumple los estándares de codificación definidos en la AA1-EV02.
  • Se parte de lo hecho antes: diagramas, historias de usuario, prototipos y el plan de trabajo.
  • Los ZIP se nombran NOMBRE_APELLIDO_AA#_EV##.
  • Hay 4 videos en total: AA1-EV05, AA3-EV02, AA5-EV02 y AA5-EV04.
  • Cada evidencia se evalúa con su lista de chequeo IE-GA7-220501096-AA#-EV##.
