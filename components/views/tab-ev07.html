Script bases de datos del proyecto

Con la estructura de la EV02 ya creada, genera el script SQL del modelo físico de tu proyecto formativo y expórtalo desde MySQL Workbench. Las capturas muestran el procedimiento paso a paso con el esquema juego; tú seleccionas el esquema de tu proyecto.

Criterio de evaluación

Implementa restricciones en la base de datos de acuerdo con las reglas de diseño. Instrumento: lista de chequeo IE-GA6-220501096-AA2-EV03. El producto es un archivo ZIP con los archivos .sql del modelo físico que corresponden a los diseños hechos en MySQL Workbench.

Concepto

¿Qué es el script de la base de datos?

Es un archivo de texto con todas las sentencias SQL que reconstruyen la base de datos en cualquier servidor MySQL: CREATE DATABASE, cada CREATE TABLE con sus llaves y restricciones y, si se quiere, los INSERT con los datos. Sirve como copia de seguridad y para entregar o instalar el proyecto en otro equipo.

Data Export (mysqldump)

Parte de la base que ya existe en el servidor y la vuelca a un archivo .sql. Es el procedimiento de las capturas.

Forward Engineer

Parte del diagrama del modelo (.mwb) y genera el script de creación. Se explica al final como alternativa.

Paso a paso

Exportar el script con Data Export

  1. Verifica que la base de datos del proyecto exista

    En la pestaña Schemas pulsa el botón de actualizar y despliega tu esquema. En Tables deben aparecer todas las tablas del proyecto creadas en la EV02.

  2. Abre Administration › Data Export

    Cambia a la pestaña Administration. En el grupo Management elige Data Export. También está en el menú Server › Data Export.

  3. Selecciona el esquema, las tablas y las opciones

    Marca tu esquema en la lista izquierda; a la derecha quedan marcadas todas sus tablas (en el ejemplo, 4 tables selected). Luego configura:

    Opciones recomendadas de Data Export
    Opción Valor recomendado
    Tipo de volcado Dump Structure and Data (estructura y datos) o Dump Structure Only si solo quieres el modelo físico.
    Export to Self-Contained File Actívalo para obtener un único archivo. Pulsa … y cambia Untitled.sql por un nombre claro, por ejemplo script_proyecto.sql.
    Include Create Schema Márcalo. Agrega CREATE DATABASE y USE al inicio, de modo que el script cree la base completa por sí solo.
    Dump Stored Procedures, Events y Triggers Márcalos solo si tu proyecto los tiene.

  4. Pulsa Start Export y acepta el aviso de versión

    Si Workbench trae un mysqldump más antiguo que tu servidor (aquí 8.0.36 frente a 9.0.1), muestra mysqldump Version Mismatch. Para tablas, llaves y datos el volcado funciona igual: pulsa Continue Anyway.

  5. Confirma que la exportación terminó

    La pestaña Export Progress debe decir Export Completed y 4 of 4 exported (el número de tus tablas). El log muestra el comando mysqldump usado y la ruta del archivo generado.

  6. Revisa el archivo generado

    Ábrelo con VS Code o desde Workbench (File › Open SQL Script). Debe contener un CREATE TABLE por tabla con su PRIMARY KEY y sus CONSTRAINT … FOREIGN KEY. Así se ve un fragmento típico: 

    -- Table structure for table `pedido`
DROP TABLE IF EXISTS `pedido`;
CREATE TABLE `pedido` (
  `Id_pedido` int NOT NULL AUTO_INCREMENT,
  `id_user` int NOT NULL,
  `Fecha` date NOT NULL,
  PRIMARY KEY (`Id_pedido`),
  KEY `id_user` (`id_user`),
  CONSTRAINT `pedido_ibfk_1` FOREIGN KEY (`id_user`)
    REFERENCES `Users` (`id_user`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

  7. Comprueba que el script funciona

    La prueba definitiva es restaurarlo: en Administration › Data Import/Restore elige Import from Self-Contained File, selecciona tu .sql y pulsa Start Import. Si marcaste Include Create Schema, la base se recrea sola. Captura el resultado para tu evidencia.

Alternativa: generar el script desde el modelo

Si diseñaste el diagrama en Workbench (.mwb), ábrelo y ve a File › Export › Forward Engineer SQL CREATE Script. Elige la ruta del archivo, marca Generate DROP Statements Before Each CREATE Statement si quieres poder ejecutarlo varias veces, revisa los objetos y pulsa Finish. Obtienes solo la estructura, sin datos.

Contenido del ZIP

  • Archivo .sql con el script de la base de datos del proyecto formativo (todas las tablas, llaves y restricciones).
  • El script debe corresponder a los diseños hechos en MySQL Workbench.
  • Recomendado: incluir también el modelo .mwb y verificar que el script se importa sin errores.
