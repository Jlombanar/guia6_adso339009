Concepto 1

¿Qué es Tailwind CSS?

Es un framework de CSS utility-first: en lugar de escribir reglas en un archivo aparte, se aplican clases pequeñas que hacen una sola cosa (p-4 da relleno, text-center centra el texto) directamente en el HTML. Tailwind genera el CSS solo de las clases que usas.

CSS tradicional

<button class="boton">Enviar</button>

.boton {
  background: #39a900;
  color: white;
  padding: 8px 16px;
  border-radius: 8px;
}

Con Tailwind

<button class="bg-green-600 text-white
  px-4 py-2 rounded-lg">
  Enviar
</button>
Ventajas y cuidados al usar Tailwind
Ventajas Cuidados
No inventas nombres de clases ni cambias de archivo a cada rato. El HTML se llena de clases; agrupa lo repetido en componentes.
Diseño responsivo con prefijos: md:, lg:. Hay que aprender los nombres de las utilidades.
Escala de colores y espacios consistente en todo el sitio. No reemplaza saber CSS: cada clase es una propiedad CSS.
Paso a paso

Instalar Tailwind por CDN

La forma más rápida: no se instala nada en el equipo, solo se agrega una etiqueta <script>. El navegador lee las clases de la página y genera el CSS al vuelo.

  1. Crea la carpeta y el archivo index.html

    Abre VS Code, crea la carpeta tutorial y dentro el archivo index.html. Escribe ! y pulsa Tab para generar la estructura HTML5.

  2. Agrega el script de Tailwind en el <head>

    Fija la versión en la URL para que tu página no cambie sola.

    <head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Mi tutorial</title>
  <script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4.3.3"></script>
</head>

  3. Comprueba que funciona

    Abre el archivo con Live Server. Si el título se ve grande, verde y centrado, Tailwind está activo. 

    <body>
  <h1 class="text-4xl font-bold text-green-600 text-center mt-10">
    ¡Hola, Tailwind!
  </h1>
</body>

  4. Opcional: agrega tus propios colores

    Con @theme creas utilidades nuevas. Después de esto existen bg-sena, text-sena, border-sena… 

    <style type="text/tailwindcss">
  @theme {
    --color-sena: #39a900;
    --color-azul: #0067ac;
  }
</style>

El CDN es para aprender y prototipar

El script del CDN necesita internet y genera el CSS en cada visita. En un proyecto real se instala con npm (Tailwind CLI o Vite) para obtener un archivo CSS pequeño y optimizado. En tutoriales antiguos verás cdn.tailwindcss.com: es el CDN de la versión 3, que se configura con tailwind.config en vez de @theme.

Concepto 2

Las utilidades más usadas

La escala de espacios va de 4 en 4 píxeles: p-1 = 4 px, p-4 = 16 px, p-8 = 32 px.

Utilidades de Tailwind y su CSS equivalente
Grupo Clases de ejemplo CSS equivalente
Texto text-xl font-bold text-center font-size, font-weight, text-align
Color text-stone-700 bg-green-100 color, background-color
Espaciado p-4 px-6 mt-8 gap-4 padding, margin, gap

Practica

Ejercicios prácticos

Pega cada ejercicio dentro del <body> de tu archivo de prueba, obsérvalo en el navegador y luego resuelve el reto.

  1. Tipografía y color

    <h1 class="text-3xl font-extrabold text-green-700">Mi tutorial</h1>
<p class="text-lg text-stone-600 italic">Aprende paso a paso.</p>

    Reto: cambia el título a text-5xl y color azul (text-blue-700), y subraya el párrafo con underline.

  2. Modelo de caja: relleno, margen y borde

    <div class="m-6 p-6 border-2 border-green-600 rounded-xl bg-green-50">
  Caja con margen, relleno y borde redondeado
</div>

    Reto: deja solo relleno horizontal (px-10) y agrega una sombra (shadow-lg).

  3. Barra de navegación con Flexbox

    <nav class="flex items-center justify-between bg-stone-800 p-4 text-white">
  <strong>Mi sitio</strong>
  <ul class="flex gap-6">
    <li><a href="#" class="hover:text-green-400">Inicio</a></li>
    <li><a href="#" class="hover:text-green-400">Temas</a></li>
  </ul>
</nav>

    Reto: agrega un tercer enlace «Contacto» y cambia justify-between por justify-center. ¿Qué ocurre?

  4. Rejilla responsiva con Grid

    <section class="grid grid-cols-1 gap-4 p-4 sm:grid-cols-2 lg:grid-cols-3">
  <div class="rounded-lg bg-green-200 p-6">1</div>
  <div class="rounded-lg bg-green-300 p-6">2</div>
  <div class="rounded-lg bg-green-400 p-6">3</div>
</section>

    Reto: reduce el ancho de la ventana (o usa F12 › modo dispositivo) y observa cómo pasa de 3 a 2 y a 1 columna.

  5. Botón con estados

    <button class="rounded-lg bg-green-600 px-5 py-3 font-semibold text-white
  transition hover:bg-green-800 focus:outline-none focus:ring-4
  focus:ring-green-300 active:scale-95">
  Comenzar
</button>

    Reto: navega con Tab hasta el botón: el anillo de foco es accesibilidad. Crea una versión naranja.

  6. Componente: tarjeta de un tema

    Es la pieza que se repite en la evidencia: título, imagen y descripción.

    <article id="tema1" class="max-w-sm overflow-hidden rounded-2xl bg-white shadow-md">
  <img src="img/tema1.jpg" alt="Descripción de la imagen" class="h-48 w-full object-cover" />
  <div class="p-5">
    <h2 class="text-xl font-bold text-green-700">1. Título del tema</h2>
    <p class="mt-2 text-stone-600">Descripción del tema.</p>
  </div>
</article>

    Reto: duplica la tarjeta tres veces dentro de la rejilla del ejercicio 4.
