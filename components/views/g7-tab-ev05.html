Antes de grabar

Tres detalles de la guía que debes saber

Si copias los comandos de la guía tal cual, dos de ellos fallan. Explicar por qué en el video demuestra que entiendes Git.

1. master o main

La guía usa master, el nombre antiguo de la rama principal. Desde 2020 GitHub usa main, y en la AA1-EV04 configuraste init.defaultBranch main. Revisa tu rama con git branch y usa ese nombre en el push. Si escribes una rama que no existe, Git responde src refspec master does not match any.

2. github u origin

En el paso 1 la guía llama al remoto github, pero en el paso 3 hace push origin. Ese nombre es solo un apodo para la URL: si solo agregaste github, el remoto origin no existe y el push falla. Usa github en los dos pasos.

3. Se necesita al menos un commit

No se puede subir un repositorio vacío. Antes del paso 2, el repositorio local debe tener un commit (un README.md basta). Crea también el repositorio de GitHub sin README, para que no haya conflicto en el primer push.

Cómo terminar cat > kotlin.txt

El comando espera que escribas el contenido del archivo. Escribe tu nombre, pulsa Enter, escribe tu correo, pulsa Enter y termina con Ctrl + D. Funciona en Git Bash, en la Terminal de macOS y en Linux; no en PowerShell ni en CMD.

Paso 0 · Preparación

El repositorio local del programa

Abre Git Bash (o la Terminal) y crea la carpeta del programa con un primer commit. Puedes hacerlo antes de grabar o al comienzo del video. 

git --version                          # Git está instalado
git config --global user.name          # muestra tu nombre configurado
git config --global user.email         # muestra tu correo configurado

mkdir Programa-Git
cd Programa-Git
git init                               # crea el repositorio local (.git)
echo "# Programa-Git" > README.md
git add README.md
git commit -m "Commit inicial"
git branch                             # muestra el nombre de tu rama: main
Paso 1

Crear el repositorio remoto y conectarlo

  1. Crea el repositorio en GitHub

    En github.com pulsa + › New repository. Nombre: Programa-Git. Visibilidad: Public. No marques «Add a README file», ni .gitignore, ni licencia. Pulsa Create repository.

  2. Copia la URL HTTPS

    En la página del repositorio nuevo, con la opción HTTPS seleccionada, copia una dirección como https://github.com/tu-usuario/Programa-Git.git.

  3. Agrega el remoto y muéstralo

    git remote add guarda la URL con el apodo github. git remote -v lista los remotos: cada uno aparece dos veces, una para traer (fetch) y otra para enviar (push). 

git remote add github https://github.com/tu-usuario/Programa-Git.git
git remote -v

# Resultado esperado:
# github  https://github.com/tu-usuario/Programa-Git.git (fetch)
# github  https://github.com/tu-usuario/Programa-Git.git (push)
Paso 2

Subir los cambios y ver el historial

  1. Envía los commits

    git push envía los commits de la rama local al remoto. La opción -u deja enlazada tu rama con la de GitHub, para que después baste escribir git push. La primera vez, Git Credential Manager abre el navegador para iniciar sesión.

  2. Comprueba en GitHub

    Recarga la página del repositorio: aparece el README.md. Pulsa el enlace Commits (el ícono de reloj junto al número de commits) para mostrar el historial de versiones, con autor, mensaje y fecha.

  3. Compara con el historial local

    git log --oneline muestra los mismos commits en la terminal. Si los identificadores coinciden con los de GitHub, el local y el remoto están sincronizados. 

git push -u github main     # la guía escribe: git push github master
git log --oneline
Paso 3

Agregar kotlin.txt y subirlo

Este paso recorre el ciclo completo de Git: crear un cambio, prepararlo, confirmarlo y publicarlo. 

cat > kotlin.txt
Nombre Apellido                # escribe tu nombre de usuario y pulsa Enter
tu-correo@ejemplo.com          # escribe tu correo, Enter y luego Ctrl + D

cat kotlin.txt                 # muestra el contenido del archivo
git status                     # kotlin.txt aparece en rojo: sin seguimiento
git add .                      # lo pasa al área de preparación
git status                     # ahora aparece en verde: listo para el commit
git commit -m "Añadido datos."
git push github main           # la guía escribe: git push origin master
git log --oneline

Termina el video en GitHub: abre kotlin.txt para que se vea tu nombre y tu correo, y vuelve a Commits para mostrar que ahora hay dos versiones: «Commit inicial» y «Añadido datos.».
