Los mockups de la AA3-EV02 se convierten en una interfaz real con HTML y CSS. Aquí defines colores, tipografía, estilos de cada componente, menús y comportamiento en distintos tamaños de pantalla. El ejemplo resuelto es la interfaz web adaptable de la tienda deportes con su guía de estilos.

Criterio de evaluación

Crea interfaces de usuario aplicando buenas prácticas de usabilidad y accesibilidad. Instrumento: lista de chequeo IE-GA6-220501096-AA3-EV03. El producto es la interfaz gráfica del software en una carpeta comprimida ZIP con sus archivos.

Concepto 1

Lo que la guía pide definir

Cada decisión se guarda una sola vez en CSS y se reutiliza en todas las pantallas.

Colores

Variables en :root: --color-primario, --color-accion, --color-peligro… Cada una con contraste comprobado.

Estilos

Tipografía, espaciado en escala de 4 px, bordes y sombras. Cada componente con sus estados: hover, foco, error, deshabilitado.

Menús

Barra de pestañas inferior en móvil y menú horizontal en escritorio. La página activa se marca con aria-current="page".

Usabilidad

Áreas táctiles de 44 px, etiquetas visibles, foco visible al navegar con teclado y enlace «Saltar al contenido».

Concepto 2

Variables CSS y diseño móvil primero

Las variables guardan la guía de estilos; las consultas de medios cambian la distribución según el ancho. Se escribe primero el estilo para móvil y se agregan cambios con min-width.

css/base.css

:root {
  --color-primario: #2b7a00; /* 5.4:1 */
  --color-accion: #b84a00;   /* 5.2:1 */
  --color-enlace: #0067ac;   /* 5.9:1 */
  --texto-base: 1rem;        /* 16 px */
  --alto-control: 44px;
}

.btn {
  min-height: var(--alto-control);
  background: var(--color-primario);
}

css/layout.css

/* Móvil: menú fijo abajo */
.menu {
  position: fixed;
  inset: auto 0 0 0;
}
.rejilla-productos {
  grid-template-columns: repeat(2, 1fr);
}

/* Desde 768 px: menú arriba */
@media (min-width: 768px) {
  .menu { position: static; }
}
Paso a paso

Cómo construir la interfaz

  1. Crea la estructura de carpetas

    Una página HTML por pantalla del prototipo, y las carpetas css/ e img/. Usa rutas relativas.

  2. Pasa la guía visual a variables

    En Figma, el modo desarrollador (Shift + D) muestra colores, tamaños y espacios. Cópialos a :root en base.css.

  3. Escribe el HTML semántico de cada pantalla

    <header> con <nav>, <main>, <form> con <label>, <article> para cada producto, <table> para los pedidos.

  4. Estiliza los componentes

    En componentes.css: botón, campo, insignia, tarjeta, tabla. Usa nombres BEM (.campo__entrada, .btn--secundario) y define cada estado.

  5. Diseña los menús y la distribución

    En layout.css: encabezado, menú y rejillas. Prueba con las herramientas del navegador (F12 › modo dispositivo) en 360, 768 y 1280 px.

  6. Arma la guía de estilos

    Una página index.html que muestre colores, tipografía, botones, campos y menús, con enlaces a todas las pantallas. Es la prueba de que los estilos son coherentes.

  7. Revisa la accesibilidad

    Recorre todo con Tab: el foco debe verse siempre. Pasa Lighthouse (F12 › Lighthouse › Accessibility) y corrige lo que marque.
