Concepto 1

¿Qué es una herramienta de repositorio?

Una herramienta de control de versiones guarda la historia completa de un proyecto. Cada vez que confirmas un cambio (un commit) registra qué archivos cambiaron, quién lo hizo, cuándo y por qué. El repositorio es la carpeta del proyecto más ese historial.

Repositorio local frente a repositorio remoto
Característica Repositorio local · Git Repositorio remoto · GitHub
Dónde estáEn tu computador, en la carpeta oculta .gitEn un servidor en internet
Para qué sirveTrabajar, hacer commits y ramas, incluso sin internetCopia de seguridad, compartir y colaborar
Quién lo veSolo túTú y quien tenga permiso (o todos, si es público)
Cómo se sincronizagit push envía tus commitsgit pull y git clone traen los cambios

Git y GitHub no son lo mismo

Git es el programa que instalas: lo creó Linus Torvalds en 2005, es gratuito y funciona sin internet. GitHub es la página web donde publicas tus repositorios de Git; existe desde 2008, es de Microsoft desde 2018 y agrega pull requests, Issues, Projects y Actions.

Concepto 2

¿Por qué es importante?

Nada se pierde y se puede volver atrás

Cada versión queda guardada. Si un cambio daña el programa, regresas a la versión que funcionaba.

Trabajo en equipo sin pisarse

Cada persona trabaja en su rama y luego se integran los cambios con un pull request que otro revisa.

Copia de seguridad en la nube

Si se daña o se pierde el computador, el proyecto completo está en GitHub.

Portafolio profesional

Tu perfil de GitHub muestra a las empresas lo que sabes hacer, y GitHub Actions prueba tu código automáticamente.

Concepto 3

La herramienta número uno de los desarrolladores

En la encuesta de Stack Overflow de 2022, más del 93 % de los desarrolladores dijo usar Git, muy por encima de cualquier otro sistema. GitHub superó en 2023 los 100 millones de desarrolladores. Casi toda oferta de trabajo de desarrollo pide saber usar Git.

Manual · Parte A

Instalar y configurar Git (local)

Toma un pantallazo en cada paso: son los que pide la guía. Necesitas permisos de administrador y Visual Studio Code instalado.

  1. Descarga el instalador

    En Windows entra a git-scm.com/downloads/win y descarga Git for Windows de 64 bits. En macOS ejecuta xcode-select --install en la Terminal; en Ubuntu, sudo apt install git.

  2. Recorre el asistente de Windows

    Deja las opciones por defecto salvo las de la tabla de abajo. Captura al menos el editor, la rama inicial y el PATH.

  3. Instala y abre Git Bash

    Pulsa Install, marca Launch Git Bash y pulsa Finish.

  4. Verifica la instalación

    Escribe git --version. Debe responder git version 2.x.x.

  5. Configura tu identidad

    Nombre y correo con git config --global. Usa el mismo correo de tu cuenta de GitHub para que los commits aparezcan en tu perfil.

Manual · Parte B

Configurar GitHub (remoto) y conectarlo

  1. Crea la cuenta

    En github.com/signup, con un usuario profesional (nombre-apellido) y el plan Free. Como aprendiz puedes pedir GitHub Education.

  2. Activa la verificación en dos pasos

    Settings › Password and authentication › Enable two-factor authentication, con una app autenticadora. GitHub la exige para contribuir código.

  3. Crea el repositorio

    + › New repository, nombre tienda-deportes, público y sin marcar «Add a README file». Copia la dirección HTTPS.

  4. Autentica tu equipo

    GitHub ya no acepta la contraseña en la terminal. En Windows, Git Credential Manager abre el navegador en el primer push. En macOS o Linux puedes usar una llave SSH (ver el manual de ejemplo).

  5. Conecta y sube el primer commit

    Con los comandos de abajo. Captura el resultado del git push y el repositorio en GitHub con el README.

  6. Revisa la integración con VS Code

    Abre la carpeta del proyecto: el panel Control de código fuente (Ctrl + Shift + G) muestra los cambios y permite hacer commit y sincronizar. 

mkdir tienda-deportes
cd tienda-deportes
git init
echo "# Tienda Deportes" > README.md
git add README.md
git commit -m "docs: agregar README inicial"
git remote add origin https://github.com/usuario/tienda-deportes.git
git remote -v
git push -u origin main
