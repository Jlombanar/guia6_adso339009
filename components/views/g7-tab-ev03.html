Identifica herramientas de versionamiento

Git trabaja en dos niveles: un repositorio local, en tu computador, y uno remoto, en un servidor como GitHub que comparte el equipo. En esta evidencia comparas los dos en tablas de diferencias y características, y describes sus comandos básicos. Es la base teórica de la instalación (AA1-EV04) y del video (AA1-EV05).

Criterio de evaluación

Selecciona y configura herramientas de versionamiento para el control de cambios en el código. Instrumento: lista de chequeo IE-GA7-220501096-AA1-EV03. El producto es un informe técnico en PDF con portada, introducción, objetivo, tablas con diferencias y características de Git local y Git remoto, y una tabla con la descripción de sus comandos básicos.

Concepto 1

Git local y Git remoto

No compiten: se complementan. En el local trabajas rápido y sin internet; en el remoto integras el trabajo del equipo y lo respaldas.

Repositorio

La carpeta del proyecto más su historial, que Git guarda en la carpeta oculta .git.

Commit

Fotografía de los archivos en un momento, con autor, fecha y mensaje.

Rama

Línea de trabajo independiente para desarrollar una funcionalidad sin afectar la principal.

origin

Nombre que Git da por convención al repositorio remoto principal.

Concepto 3

Características de cada uno

Git local

Distribuido: cada copia tiene el historial completo. Tres áreas: directorio de trabajo, preparación y repositorio. Ramas livianas, integridad con códigos SHA y trabajo sin conexión.

Git remoto

Repositorio compartido del equipo, copia de seguridad, control de acceso y ramas protegidas, revisión de código, issues y tableros, e integración continua.

Comandos básicos de Git local y remoto

Los locales funcionan sin internet; los remotos comunican tu repositorio con GitHub. El informe de ejemplo trae la tabla completa con un ejemplo de cada uno.

Comandos de Git local
ComandoQué hace
git initCrea el repositorio
git statusMuestra qué cambió

git commit -mGuarda en el historial
git logMuestra el historial
git branchLista o crea ramas
git switchCambia de rama
git mergeUne una rama a la actual

Git remoto

Comandos de Git remoto
ComandoQué hace
git cloneDescarga un repositorio
git remote addRegistra un remoto
git remote -vLista los remotos
git pushEnvía tus commits
git push -uEnvía y enlaza la rama
git fetchDescarga sin aplicar
git pullDescarga y une
git branch -rRamas del remoto
git push --tagsEnvía las versiones
git push --deleteBorra una rama remota
# --- Git local ---
git init
git add README.md
git commit -m "docs: agregar README inicial"
git switch -c feature/catalogo
git add .
git commit -m "feat: agregar catálogo de productos"
git switch main
git merge feature/catalogo
git log --oneline

# --- Git remoto ---
git remote add origin https://github.com/usuario/tienda-deportes.git
git remote -v
git push -u origin main
git pull origin main

pull = fetch + merge

git pull descarga y une en un solo paso. Si quieres revisar antes lo que cambió en GitHub, usa git fetch y luego git merge.
