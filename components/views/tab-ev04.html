GA6-220501096-AA1-EV04 · Evidencia de producto

Elaboración de las bases de datos

Crea y manipula en MongoDB la base de datos NoSQL construida a partir del documento de la EV03. La evidencia solicita una colección parque, cinco documentos, dos actualizaciones, consultas y la eliminación de un registro.

Criterio de evaluación

Crea la base de datos integrando los objetos de acuerdo con la funcionalidad del software. El producto solicitado por la guía es un video MP4 que muestre la creación y manipulación de bases de datos NoSQL.

Antes de comenzar

Estructura del ejercicio

Base de datos

vehiculos_ev04. Nombre de ejemplo para mantener este ejercicio aislado de los datos de EV03.

Colección

parque, tal como solicita la evidencia.

Documento

Placa, número de serie, modelo, marca, kilometraje y tipo, siguiendo la estructura JSON de EV03.

Desarrollo en mongosh

Proceso de creación y manipulación

Ejecuta los pasos en orden. Se usa una base nueva para evitar modificar por accidente el trabajo previo de EV03.

  1. Selecciona la base y crea la colección

    MongoDB crea la base al crear la colección o guardar el primer documento. 

    use vehiculos_ev04
db.createCollection("parque")

  2. Inserta cinco documentos

    Conserva los campos definidos para el vehículo en EV03. MongoDB asigna un _id a cada documento. 

    db.parque.insertMany([
  { placa: "ABC123", numeroSerie: "SN-2024-001", modelo: 2024, marca: "Toyota", kilometraje: 15200, tipo: "SUV" },
  { placa: "XYZ789", numeroSerie: "SN-2023-002", modelo: 2023, marca: "Renault", kilometraje: 28400, tipo: "Sedan" },
  { placa: "JKL456", numeroSerie: "SN-2022-003", modelo: 2022, marca: "Chevrolet", kilometraje: 41700, tipo: "Camioneta" },
  { placa: "MNP321", numeroSerie: "SN-2021-004", modelo: 2021, marca: "Mazda", kilometraje: 53600, tipo: "Hatchback" },
  { placa: "RST654", numeroSerie: "SN-2020-005", modelo: 2020, marca: "Kia", kilometraje: 68900, tipo: "SUV" }
])

  3. Actualiza el primer y el último registro

    Comprueba que cada respuesta indique matchedCount: 1 y modifiedCount: 1. 

    db.parque.updateOne(
  { placa: "ABC123" },
  { $set: { kilometraje: 16000 } }
)

db.parque.updateOne(
  { placa: "RST654" },
  { $set: { kilometraje: 72000 } }
)

  4. Lista la colección completa

    Registra en el video el resultado con los cinco documentos y sus valores actualizados. 

    db.parque.find({})

  5. Borra el tercer documento

    En este conjunto de ejemplo, el tercero tiene la placa JKL456. El filtro por placa evita borrar otro registro. 

    db.parque.deleteOne({ placa: "JKL456" })

  6. Vuelve a listar y comprueba la eliminación

    La colección debe mostrar cuatro documentos; la respuesta de borrado debe indicar deletedCount: 1. 

    db.parque.find({})
db.parque.countDocuments({})

  7. Consulta por número de placa

    La guía pide una sentencia que recupere un documento según la placa. 

    db.parque.findOne({ placa: "ABC123" })
