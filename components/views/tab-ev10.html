Establecer los componentes front-end de la aplicación web

Antes de programar el front-end se decide con qué piezas se va a construir. En esta evidencia elaboras un documento que especifica la estructura de componentes de tu software y los elementos HTML que usará cada uno. El ejemplo resuelto define los componentes de la tienda deportes, a partir de su base de datos (AA2) y del prototipo en Figma (AA3).

Criterio de evaluación

Genera plantillas y estilos de acuerdo con el diseño establecido. Instrumento: lista de chequeo IE-GA6-220501096-AA4-EV02. El producto es el documento de componentes en Word, entregado en una carpeta comprimida ZIP. Como mínimo debe tener portada, introducción, objetivo y la definición de los elementos HTML a utilizar en el diseño front-end.

Concepto 1

¿Qué es un componente front-end?

Es una pieza de la interfaz que se puede reutilizar: un botón, un campo de formulario, una tarjeta de producto. Cada componente reúne tres capas y se escribe una sola vez para usarlo en todas las pantallas.

HTML · estructura

Qué es la pieza y qué contiene: <article> con imagen, título, precio y botón.

CSS · presentación

Cómo se ve: colores, tamaños, espacios y sus variantes (.btn--primario, .btn--peligro).

JS · comportamiento

Qué hace al interactuar: «Agregar» suma el producto al carrito y actualiza el contador.

Datos

Qué información muestra y de qué tabla viene: productos.Nombre, Precio, Stock.

Concepto 2

Diseño atómico: organizar por niveles

La metodología Atomic Design ordena los componentes de lo más pequeño a lo más grande. Las piezas pequeñas se combinan para formar las grandes, y un cambio en un átomo se refleja en todas las pantallas.

Niveles del diseño atómico con ejemplos de la tienda deportes
Nivel Qué es Ejemplo en la tienda
Átomos Elementos HTML básicos con estilo propio. Botón, campo de texto, etiqueta, insignia de stock, logo
Moléculas Grupo pequeño de átomos con una función. Campo de formulario (etiqueta + entrada + error), buscador, tarjeta de producto
Organismos Secciones completas. Encabezado con navegación, formulario de login, rejilla del catálogo, tabla de pedidos
Plantillas Esqueleto que ubica los organismos. Plantilla de autenticación y plantilla de tienda
Páginas Plantilla con datos reales. login.html, catalogo.html, carrito.html…
Concepto 3

Elementos HTML que debes definir

Es la parte obligatoria del documento. Usa HTML5 semántico: cada etiqueta describe su contenido, y así el lector de pantalla anuncia «navegación», «principal» o «formulario». Para cada elemento indica para qué sirve y en qué pantalla lo usarás.

Elementos HTML por grupo y su uso en la tienda
Grupo Elementos Uso en la tienda
Estructura <header> <nav> <main> <section> <article> <aside> <footer> Encabezado y menú, contenido de cada página, tarjetas, resumen del carrito, pie
Contenido <h1>–<h3> <p> <ul> <a> <img alt> <strong> <data> <time> Títulos, menú, fotos de productos, precio, fecha del pedido
Formularios <form> <label for> <input type="email|password|number|search"> <fieldset> <button> <output> Login, registro, buscador, cantidad en el carrito, total

Interactivos <dialog> Ventana modal de detalle del pedido y confirmación
Accesibilidad lang alt aria-label aria-live aria-invalid aria-current Botones con ícono, contador del carrito, errores de formulario, menú activo
Paso a paso

Cómo elaborar el documento

Trabaja sobre tu proyecto formativo. Ten a la mano los requerimientos, el modelo de la base de datos y el prototipo de la AA3.

  1. Lista las pantallas

    Recorre el prototipo y anota cada pantalla con el requerimiento que atiende. En la tienda: Login (RF-02), Registro (RF-01), Catálogo (RF-03, RF-04), Carrito (RF-05) y Mis pedidos (RF-06).

  2. Encierra lo que se repite

    En cada pantalla marca los bloques que aparecen más de una vez: botones, campos, tarjetas, el encabezado. Cada bloque repetido es un componente. Si en Figma ya los creaste como componentes, úsalos tal cual.

  3. Clasifícalos por nivel y dibuja el árbol

    Ubica cada componente como átomo, molécula u organismo y muestra cómo se anidan dentro de cada página.

  4. Define los elementos HTML

    Haz las tablas del Concepto 3 con tus propios elementos: etiqueta, uso y pantalla donde aparece. Es el contenido mínimo que pide la guía.

  5. Escribe una ficha por componente

    Propósito, elementos HTML, variantes, estados (normal, hover, foco, deshabilitado, error), datos que muestra, función JS y atributos de accesibilidad. Incluye el fragmento HTML de los más importantes.

  6. Fija carpetas, nombres y estilos

    Estructura de archivos, convención de clases (por ejemplo BEM: bloque__elemento--modificador), paleta, tipografía, espaciado y puntos de quiebre. Esto es lo que aplicarás en la AA4-EV03.

  7. Arma el documento

    Portada, tabla de contenido, introducción, objetivos y los apartados anteriores, cerrando con conclusiones y referencias. En Word usa los estilos Título 1 y Título 2 para generar la tabla de contenido automática.

Molécula: campo de formulario

<div class="campo">
  <label class="campo__etiqueta" for="correo">Correo</label>
  <input class="campo__entrada" id="correo"
    type="email" autocomplete="email" required
    aria-describedby="correo-error" />
  <p class="campo__error" id="correo-error" hidden>
    Escribe un correo válido.
  </p>
</div>

  <button class="btn btn--accion" type="button">
    Agregar
  </button>
</article>
