Tutorial práctico de Tailwind CSS

Aprende a dar estilo a una página web escribiendo clases directamente en el HTML. Cada tema trae una explicación, el código listo para copiar y el resultado funcionando.

1. Instalación por CDN

Un CDN es un servidor que entrega archivos por internet. Basta con agregar una etiqueta <script> en el <head>: el navegador lee las clases de la página y genera el CSS. Fija la versión en la URL para que tu diseño no cambie solo.

2. Tipografía y colores

El tamaño va de text-xs a text-9xl y el grosor de font-thin a font-black. Los colores siguen el patrón propiedad-color-tono: en text-green-600, el tono va de 50 (claro) a 950 (oscuro). Con bg- se pinta el fondo.

3. Espaciado y modelo de caja

p- es el relleno interno (padding) y m- el margen externo. Cada unidad equivale a 4 px: p-4 = 16 px. Agrega x o y para un solo eje (px-6, my-2) o t, r, b, l para un lado.

4. Flexbox: barra de navegación

flex pone los hijos en fila. justify-between reparte el espacio en el eje horizontal e items-center los centra en el vertical. gap-6 separa los elementos sin usar márgenes.

5. Grid responsivo: galería

grid grid-cols-1 apila en el celular. Los prefijos responsivos cambian el diseño desde cierto ancho: sm: 640 px, md: 768 px, lg: 1024 px. Reduce la ventana para ver cómo pasa de 3 a 2 y a 1 columna.

6. Estados: hover y focus

Un prefijo aplica la clase solo en un estado: hover: al pasar el mouse, focus: al llegar con el teclado y active: al hacer clic. El anillo de focus:ring-4 ayuda a quien navega con Tab: es una práctica de accesibilidad.
