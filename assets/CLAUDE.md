1. **Consulta de Contexto Institucional:** Lee obligatoriamente `.ai/CONTEXTO_ADSO.md` para entender el marco pedagógico y la ficha.
2. **Estándares de Código y Estilos:** Sigue estrictamente `.ai/REGLAS_CODIGO.md` (HTML5 semántico estricto, Tailwind CSS v3+, JavaScript Vanilla modular ES6+, WCAG 2.1 AA).
3. **Arquitectura Modular de Componentes:** Todas las vistas deben gestionarse en `components/` (`layout/`, `views/`, `modals/`). No acumular bloques masivos de código en páginas shell principales (`< 120` líneas).
